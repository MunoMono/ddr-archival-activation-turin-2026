# Figures

This directory is reserved for publication-quality figures associated with the Turin 2026 paper.

Planned contents include:

- evidential pathways across the 12 experimental cases;
- retrieval trail for an archive-first query;
- temporal comparison in the Design Education Unit case;
- scoped missingness in the DDR closure case.

Prefer vector SVG where possible and high-resolution PNG for interface captures. Each public figure should include a concise caption and, where required, a rights note.
