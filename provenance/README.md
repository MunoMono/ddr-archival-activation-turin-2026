# Provenance benchmark

The research instrument implements a bounded C2PA Content Credentials research workflow for selected outputs.

The workflow records source passages as ingredients, captures the creation action and checks resulting manifests for validity and hard-binding tamper detection.

This work tests technical interoperability with the C2PA data model and validation tooling. It does **not** claim C2PA conformance, certification or media authenticity. Trust List onboarding, an approved certificate authority, trusted timestamps and a managed external signing boundary remain outside the scope of the PhD prototype.

Benchmark files and validation outputs can be added here for the frozen conference-paper release.
